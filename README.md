# مساعد (Musaed)

A Saudi-dialect voice assistant MVP. One page, runs in the browser, talks and answers with a female voice.

- Conversation only: no calls, messages, email or calendar in this version.
- Voice in and voice out use Google's Gemini Live API.
- Each user pastes their own Gemini API key in the app's settings. The key is stored on that device only and is never part of this repository.

Open the page on an iPhone in Safari, paste the key, tap the circle and talk.
